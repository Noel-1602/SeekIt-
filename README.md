# Unfog

Unfog — Inverse fog-of-war travel journal on an interactive map.

**Tech Stack**: React, Vite, TypeScript, MapLibre GL JS, OpenFreeMap, H3-js, Dexie.

### Quick Start
```bash
npm install && npm run dev
```

**Zero-Server & Privacy**: All data remains local in IndexedDB; zero trackers, zero external API keys.

**Map Attribution**: Data by OpenFreeMap, OpenMapTiles, and © [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors.
